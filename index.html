⚙️ 数据从哪来：每日流水线六步（实装）

每天早上由 GitHub Actions 自动运行 thoradar_engine.py 产出本页全部数据。未配置大模型密钥时自动降级为启发式模式（仅按期刊层级与研究类型收录），并在文献卡片上如实标注。设计思路受 AIHOT 开源框架 启发。

阶段 实现 说明与边界（诚实声明）
1. 采集 PubMed ESearch datetype=crdt（按入库日）+ [Title/Abstract] 自由词，EFetch 取全量元数据 电子先发（Ahead of Print）不等 MeSH 词即抓，避免按纸质发表日漏检
2. 期刊定级 五重主键索引：ISSN-L / P-ISSN / E-ISSN / NlmUniqueID / ISO 缩写 S/A 级白名单豁免（无标准摘要的短文也保留）；未收录期刊按 B 级处理
3. 预筛 LLM 每 20 篇批量初筛；无密钥时退化为关键词启发式 过滤细胞实验与无关文献，控制成本；预筛失败时该批全保留、不漏检
4. 精评 LLM 结构化 PICO 提取 + 反阳性偏倚条款（严谨阴性研究同等赋分） 评分仅供排序参考，不构成任何临床建议
5. 四元组核验 数值存在性 + 语境锚定：数字须在原摘要出现，且所在句含该终点指标关键词 fail-closed：未通过即卡片标 ⚠，绝不静默放行。注意：文本比对无法识别「同数值不同人群」的高级张冠李戴，重要文献请点开英文原摘要复核
6. 产出 写 data/*.json 与早报 Markdown，按注入标记更新本页数据区 标记缺失即拒绝写入，杜绝静默不更新
