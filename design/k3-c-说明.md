# 胸科雷达 C 版设计说明

- **方向**：采用「六条研究线路 × 文献时刻表」，以全宽横向线路图区别刊物长文、门户大卡与放射雷达，形成 C 版独立构图。
- **首屏**：六个主题各占一条线路，36 篇真实文献各占一个节点；横序沿用日档，节点高度表示预筛分，点击或键盘聚焦均可进入阅读。
- **数据**：仅内嵌 `2026-10-17` 真实日档与状态覆盖层所需字段，剔除作者及机构字段；精选真实为 0，明确空置而不拿高分文献凑数。
- **阅读**：时刻表保持紧凑，详情用研究设计／实际结果／作者结论／AI 疑点四分离；缺字段留白，摘要只保留开头两句，PubMed／DOI 官方链接可达。
- **四层**：今日动态、编辑精选、趋势台账、主题档案共用同一份数据；趋势页只讲单日事实，不用单日数据虚构周月走势。
- **视觉**：冻结 Trackeep 色板与三套字体，以无衬线大标题、细线、陶土节点和全宽六线图建立现代索引感，另支持深色夜读。
- **交付**：`design/k3-c.html` 为单文件、零外部依赖，`file://` 离线渲染；桌面 1440 与手机 390 截图在 `design/shots-k3/`。
- **自验**：两张截图已目验无破版；390 iframe 另跑 20 项检查全部通过，覆盖六线 36 节点、横向溢出、长标题、展开、筛选、搜索、弹窗与明暗切换。
