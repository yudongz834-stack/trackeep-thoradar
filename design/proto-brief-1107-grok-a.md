# 任务：ThorRadar 界面交互改造原型（两版）

## 背景与现状痛点（PI 原话转译）
现站 https://thoradar.online/ 是「一锤子布局」：左信号队列＋中央雷达盘永久占 C 位＋右侧锁定详情，三区平铺。PI 的四条不满：
1. 雷达盘只该是「概览」，不能永久霸占主视觉区
2. 看文章要有自己的视图（切换交互），雷达让位
3. 个性化设置（现在右侧 420px 抽屉）也要能全屏展开，同样走切换交互
4. 阅读列表「标题显示不全＝用户难浏览」：目标是让人一眼看懂文章在讲什么→想点进去；而不是先费劲看清标题才决定点不点。信息化＋视觉化双充分

## 交付物（单版自包含 HTML 原型，可点、可切、全 mock 无网络——本单只做一个文件，先落盘保命再打磨）
- **本次只交付版本 A：g-proto-a-view-radar.html**：三视图切换框架，雷达＝独立视图。顶栏视图切换器（概览／阅读／个性化），雷达切走后不留挂件，靠 tab 回来
- **版本 B（g-proto-b-widget.html）**：本单不交付 B（另一单负责），不要建此文件
- 交付文件名固定：g-proto-a-view-radar.html；包含下述全部设计模块

## 必做设计模块
1. **视图切换器**：统一的切换语言（建议顶栏分段控制或等效物），每次只聚焦一个视图；键盘可达
2. **阅读视图（重头戏）**：文章卡信息化＋视觉化双充分——
   - 标题完整展示（两行 clamp 废除），中英双语层次分明
   - 一眼看懂三件套：这篇做什么（主题域色标）／怎么做（研究类型图形语言：RCT/队列/综述/AI 各有形状或图标）／发现了什么（一句话结论前置，数据点可视化如 76 分环）
   - 卡片密度分级：紧凑浏览态 ↔ 展开沉浸态
3. **雷达盘美化**：信号点按评分映射大小/色深/光晕，悬停浮现摘要卡，扇区色带更精致；点不要太密时保持呼吸感
4. **个性化全屏视图**：三块入口全做出来——
   - 阵地方位主题编辑器（用户点「医学AI与数字医学」类方位可编辑其主题关键词；编辑后 AI 检索分类跟随用户口径——原型里做成可交互的编辑态 mock）
   - 期刊分类勾选导航（按类别分组的批量勾选，替代平铺列表）
   - 期刊合集自由增删＋「池外刊添加」入口（用户可加名册外的任意期刊，原型做 UI mock 即可）
