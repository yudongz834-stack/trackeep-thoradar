# K3-B · 晨扫信号台设计说明
- **第三方向**：不做门户列表，也不做刊物长文；把每日晨读设计成一座可操作的「信号探测台」，核心是发现、锁定、扫完。
- **空间编码**：六个专科占据六个雷达扇区；越靠近圆心评分越高；方块、空心圆、圆点分别表示 RCT、队列与待评定研究。
- **三栏协同**：左侧过滤并进入晨扫队列，中央点按信号，右侧立即锁定题录、评分、摘要导读与官方链接，形成连续动作而非静态陈列。
- **真实交互**：支持标题/期刊/编号检索、专科与研究类型过滤、前后切换、已扫计数及明暗主题；键盘 `/`、方向键、Esc 亦可操作。
- **数据与诚实**：内嵌 2026-10-17 的 36 篇真实题录及摘要前两句，不带作者/机构字段；精选为 0 时明确留空，未生成的结论与疑点不硬写。
- **视觉语言**：冻结 Trackeep token 不动，以暖纸底、陶土信号和等宽仪表字构成轻盈的临床雷达，而非深色军事风。
- **移动重排**：390px 下按「雷达→详情→队列」单列排列，触点、长标题、筛选区与按钮均收进视口，无横向溢出。
- **自验**：`shots-k3/desktop-1440-b.png` 与 `mobile-390-b.png` 为交付主图；另存手机长图和深色图，渲染后 36 队列项、36 信号点、6 扇区标签均通过计数核验。
