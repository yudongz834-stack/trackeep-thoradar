# 胸科雷达「胸科」定义 v2（四席外审后·待 PI 终裁一处）

外审席位：GPT-6-Astra xhigh / Gemini 3.8 / Grok 4.7 / Mimo 2.6 Flash（盲评，互不见面）。
20 个边界案例：18 案四席全票；2 案分歧（均卡儿科外科线：新生儿膈疝 2:2、儿童气胸 3:1 不收）。

## 总纲
研究回答的**主要问题**，落在「胸内器官或呼吸系统」的专科管辖域（胸外科 ∪ 呼吸科 ∪ 胸部肿瘤科的病），且满足人群与研究对象限制——**收**；不在——**不收**。沾边（靶点/影像/方法/概念相同）不救。

## 判案四步（判官按序执行，先到先定）
1. **定主要问题**：＝干预/暴露靶向的疾病，或主要终点指向的器官病变。人群、宿主、场景是背景不是问题；病名与终点分裂时看终点与干预靶向（CPAP 治睡眠呼吸暂停但终点＝房颤负荷→问题在心→不收；狼疮患者肺间质受累识别→问题在肺→收）。训练集含胸科数据、或仅子组/次要分析，不构成主要问题。
2. **归域**：主要问题的病在不在收录域四圈（下）。**胸内问题例外优先于原发科室排除**：它科原发病但问题落在胸内器官（乳腺癌肺转移的局部治疗、原发纵隔大 B 细胞淋巴瘤、胸骨后甲状腺肿）→收。
3. **查排除域**（命中即不收，例外通道救回的除外）：
   - 心脏与大血管（心梗/冠脉/心衰/心律/瓣膜/主动脉）；肺高压按病因分流——CTEPH/肺源性收，左心源性不收（术式谁做不改病域：肺动脉内膜剥脱归心外做也收）；
   - **儿科【待 PI 裁 A/B】**：
     - **A（主控推荐，Gemini/Grok 持）**：＜18 岁人群的胸科病研究一律不收，唯一例外＝胸壁畸形矫形（漏斗胸/鸡胸——普胸科主刀，四席全票收）；
     - **B（Codex/Mimo 持）**：研究问题为胸内器官的外科治疗则不分年龄全收；
   - 纯耳鼻喉域（鼻炎/鼻窦炎/中耳/扁桃体；气管肿瘤例外→收）；
   - 兽医与自发动物疾病；**人源材料模型（PDX/人源化小鼠/类器官±小鼠验证）＝人类疾病研究→收**；
   - 与胸无交集的泛癌/泛外科；泛 VTE/全院血栓质控（聚焦肺栓塞→收）；吸烟作暴露、结局他科（吸烟→膀胱癌队列→不收）；胸部影像上的它科偶然发现（冠脉钙化/骨密度/肌少症→不收）。
4. **查人群与证据形态**：主要分析人群≥18（混龄队列成人结果不可分→不收；年龄未报→按成人收并标低置信）；不要求新增患者——系统综述/Meta/试验方案按其目标证据的病域判。

## 收录域（四圈；病名列举是示例，域开放）
1. **胸内器官肿瘤及癌前病变**——肺癌全家族（NSCLC/SCLC/亚型/类癌）、肺结节、食管癌（含 Barrett 与 Siewert I/II；Siewert III/近端胃不收）、纵隔/胸腺肿瘤、间皮瘤与恶性胸水；基础/转化/临床/流病/筛查/卫生经济学全收；
2. **普胸外科病**——肺/气管/食管/纵隔/胸壁/膈肌的手术相关研究（胸腔镜/机器人/无管化/肺段/食管切除/抗反流与裂孔疝修补/肺移植/胸壁矫形）；**外科面是补充不是限制**：同一疾病的内科研究按圈 3 收；
3. **成人呼吸系统疾病全谱（不限列举）**——COPD、哮喘、间质肺/肺纤维化、结核/NTM（含内科治疗）、气胸（含保守治疗）、支扩/囊性纤维化、呼吸道感染/肺炎、ARDS、肺栓塞、肺高压（肺源性/CTEPH）、睡眠呼吸暂停、尘肺/结节病/LAM/肺泡蛋白沉积症等少见肺实质病、戒烟与吸烟干预（终点须在呼吸或胸内肿瘤）；
4. **胸科场景技术**——AI/三维重建/影像组学/数字医疗，按其**解决的临床问题**归域；采集部位与数据来源不单独触发收录。
