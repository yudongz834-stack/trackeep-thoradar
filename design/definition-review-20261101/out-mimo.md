# 胸科雷达「胸科」收录定义 · 外审终审报告

**外审对象**：收录定义草案 v1（PI 授权 2026-10-31）
**外审立场**：独立裁定，不与主控/PI 对表；判定以"AI 判官只读文本、日判千篇"为压力测试条件。

---

## 一、找漏洞（10 条）

> 每条 = 文本缺陷 + 判官会犯的具体错判例。

| # | 缺陷位置 | 缺陷性质 | 会错判的具体例子 |
|---|---|---|---|
| **L1** | 总纲"呼吸系统" | 解剖学上"呼吸系统"含鼻、咽、喉、鼻窦。文本未限定"喉及以下" | 「局部晚期鼻咽癌诱导化疗＋尼妥珠单抗」→ 判官读到"呼吸系统疾病域"即收录。实际归头颈/放疗科，PI 每天会被鼻咽癌、喉癌、鼻窦炎刷屏 |
| **L2** | 收圈 1"任何研究类型全收" vs 不收圈 4/5 | 四圈与五圈**无优先级条款**，且"全收"是强语气指令，会压过约束条款 | 「KRAS G12D 抑制剂在小鼠肺腺癌模型中的药效」→ 判官依"肺癌全家族…任何研究类型全收"收录，违反"只收人类"。同理「全癌种突变图谱含肺癌亚组」被"全收"救活，绕过泛癌不收圈 |
| **L3** | 不收圈 2"大血管" | 未界定肺血管归谁；亦未界定胸水病因归属 | ①「慢性血栓栓塞性肺动脉内膜剥脱术（CTEPH）」→ 被"大血管"误杀（实为呼吸+胸外核心术式）；②「肺移植后肺静脉狭窄的球囊成形」→ 误丢。反向：③「心衰患者漏出性胸水的超声评估」→ 被圈 1"胸水"误收，原发病是心衰（不收圈 2） |
| **L4** | 不收圈 3"胸壁畸形**等**外科病不受此限" | "等"为开放式，且未枚举新生儿/先天性结构病，与"新生儿呼吸窘窘"明列不收直接撞车 | 「新生儿先天性膈疝产房手术策略」（本批案例 2）→ 判官据"新生儿呼吸病不收"丢弃，或据"等外科病"收录——同一文本两解，日判千篇必然抖动。食管闭锁、气管软化同理 |
| **L5** | 收圈 2"手术相关研究／外科面" | "手术相关"外延未定义：围术期麻醉、ICU 管理、ERAS、术前预康复、术后慢性疼痛、术后康复训练算不算 | 「胸腔镜肺癌术后慢性疼痛的围手术期预防 RCT」→ 可能读成"没有研究手术技术"而丢弃；反向，「胃肠外科 ERAS 中的肺保护通气」可能被"围术期"误收 |
| **L6** | 收圈 3"戒烟/吸烟干预" vs 总纲"主要问题在域内" | 戒烟被无条件列入收圈，但戒烟研究的主要结局常在胸域之外 | 「戒烟干预对类风湿关节炎疾病活动度的影响」、「吸烟强度与膀胱癌发病风险」（本批案例 20）→ 按圈 3 收，按总纲不收。文本两条同时为真，判官必然二选一，且两种选择都可引原文自辩 |
| **L7** | 收圈 4"研究对象必须是**上述**疾病域" ＋ 胸部外伤仅存在于判例 | ①"上述"指圈 1–3 还是总纲，指代不明；②**胸部外伤在四个收圈里没有归宿**，只在"已钉判例"，而判例不在判官三问里 | 「胸部钝性伤肺挫伤的 CT 严重度预测模型」→ 四圈逐条检索落空（非肿瘤、无手术、非圈 3 呼吸病、圈 4 指代圈 1–3 不含外伤），最终按"泛外科"丢弃——直接违反钉判例 |
| **L8** | 三问③"呼吸病另问成人吗" ＋ 圈 3 前缀"成人" | "呼吸病"未定义，年龄界限未给数值；圈 1、圈 2 无任何年龄说明 | ①「15 岁肺母细胞瘤术后辅助化疗」→ 判官把肿瘤当"呼吸病"问成人，丢弃（圈 1 应全收）；②「17 岁青少年气胸病因谱」→ 收或不收全凭心情；③16 岁哮喘按哪条，无解 |
| **L9** | 不收圈 1 例外通道"主要问题落在胸内器官上" | "落在胸内器官"缺可操作判据——**局部治疗 vs 全身治疗**、**原发在胸 vs 继发到胸**未分 | ①「肺癌脑转移的 SRS」→ 原发在域但病灶在颅内，判官可能误丢；②「乳腺癌肺转移的化疗方案对比」→ 胸内有病灶但主要问题是全身治疗，判官可能误收（与 PHERGain 判例冲突）；③「肺癌骨转移的放疗」→ 骨不在域，可能被误丢 |
| **L10** | 收圈 1"筛查/卫生经济学"＋圈 3 与四圈整体结构 | **预防与公共卫生干预（疫苗、康复、姑息、误吸预防）在四圈中多数无位置**；同时圈 1 特书"任何研究类型"，反证圈 2/3 未声明研究类型不限 | 「成人肺炎球菌疫苗预防 CAP 的 RCT」→ 四圈皆不贴：非肿瘤、非手术、圈 3 只列"感染/流感"治疗面且未声明含疫苗 → 被丢；而「儿童肺炎球菌疫苗」（本批案例 1）→ 判官据圈 3"呼吸道感染/流感"反向收录，违反儿科不收 |

**外审总评**：v1 的**总纲和本质段是好的**（管辖域逻辑、心/食管的反直觉判例都立得住），漏洞集中在三处——**① 四圈与五圈无优先级；② 三个开放式"等/上述/任何"（L4/L5/L7）；③ 年龄与解剖界限未给数值（L1/L8）**。这三类恰好都是日判千篇时的高频抖动源。

## 三、补边界（5 条，将来必炸）

**B1 · 头颈—颈胸交界解剖线**
争议：下咽癌、喉癌、颈段食管癌、气管造口、颈段气管狭窄、胸骨后甲状腺肿（已钉收）。
→ **建议**：以**环咽肌／环状软骨下缘**为线。线以下的食管、气管、支气管（全长）及其肿瘤与手术 → **收**；喉、下咽、鼻咽、鼻窦、口腔 → **不收**（即使做气管造口）；颈部食管异物、腐蚀伤、狭窄扩张 → **收**。喉癌放疗 → **不收**。

**B2 · 转移/继发灶：局部治疗 vs 全身治疗**
争议：肺癌脑转移 SRS、肺癌骨转移放疗、乳腺癌肺转移化疗、结直肠癌肺转移楔形切除。
→ **建议**：原发在域 → **收**（肺癌脑/骨/肝转移的局部治疗或以原发癌为主要问题的研究）；原发在他科 → **仅当胸内病灶是局部治疗的主要对象或主要评价终点**才收（肺转移 SBRT/消融/楔切 → 收；肺转移的化疗/靶向/免疫方案对比 → **不收**，与 PHERGain 判例同轴）。胸壁/肋骨/椎体等骨转移：原发在域 → 收；原发在他科 → 不收。

**B3 · 围术期、麻醉、ICU 与器官获取**
争议：胸科手术麻醉与通气策略、术后谵妄/慢性疼痛、ERAS 路径、术前预康复、脑死亡供体肺评估与 EVLP。
→ **建议**：研究对象为**胸科手术患者**的围术期、麻醉、ICU、康复、并发症研究 → **收**（补进圈 2）；供肺评估、体外肺灌注、移植供体管理 → **收**；非胸科手术的同类研究（虽用"肺保护通气"）→ **不收**；心脏手术的麻醉与血流动力学 → **不收**（其胸腔并发症如乳糜胸除外，见案例 18）。

**B4 · 影像上的机会性发现与多病种/泛器官模型**
争议：胸部 CT 顺带发现冠脉钙化、骨质疏松、甲状腺结节、肾上腺腺瘤、肝低密度灶；同时预测多病种的影像模型。
→ **建议**：**按终点不按部位**。终点/主要评价指标落在域内（肺结节检出、肺癌筛查剂量-检出比、COPD 纹理、间质病定量）→ **收**；终点在域外（冠脉钙化、骨量、甲状腺、肾上腺、肝）→ **不收**，无论影像采集部位；多病种模型 **以域内疾病为主要终点/预设主要亚组** → 收，**全癌种或全身多病种为部署目标** → 不收（接案例 10、11、12）。

**B5 · 症状学与综合征为主要问题**
争议：咯血、胸腔积液、呼吸困难、不明原因胸痛、吞咽困难。
→ **建议**：**咯血、胸腔积液（渗出性/恶性/脓胸来源）、呼吸困难以肺为首要鉴别对象**的诊断路径研究 → **收**；**不明原困胸痛以心血管为首要鉴别**（含冠脉 CTA 排除）→ **不收**；**漏出性胸水（心衰、肝硬化、低蛋白）按原发病 → 不收**；**吞咽困难/误吸的康复与评估（终点为吞咽功能而非肺炎）→ 不收**，终点为肺炎预防者收（接案例 15）。

## 四、修订稿（v2，改动处标注【改】）

---

### 【改】总纲
这篇研究回答的主要问题，其疾病落在**「胸内器官或呼吸系统（限喉及以下的气道、肺与胸膜腔、纵隔、胸壁、膈肌、食管、胸导管、肺血管）」**的专科管辖域，且研究对象是人类（**成人呼吸内科病另需 ≥18 岁**）——收；问题不在这个域里，哪怕靶点、方法、影像、概念跟胸科沾边——不收。
**【改】判定顺序固定：先过下方「判官三问」（总纲），再对照四圈／五圈作为印证。四圈与五圈冲突、或四圈与总纲冲突时，一律以总纲＋不收五圈为准——四圈是"收的充分条件举例"，不是独立通道。**

### 【改】本质
不是解剖上的「胸腔」，是专科管辖域——胸外科 ∪ 呼吸科 ∪ 胸部肿瘤科（含放疗）共同管的病。心脏长在胸里但不归我们；食管穿过脖子肚子但归我们。**【改】同理：鼻、咽、喉、鼻窦长在头里也不归我们；甲状腺长在颈部，但胸骨后甲状腺肿归我们。**

---

### 收 · 四个圈（符合任一，且不触犯不收五圈）

**1. 胸内器官肿瘤**——肺癌全家族（NSCLC/SCLC/各病理亚型/类癌）、肺结节、食管癌、**【改】颈段食管癌（环咽肌以下）**、纵隔/胸腺肿瘤、间皮瘤与恶性胸水、**【改】气管/支气管肿瘤、胸壁与肋骨/胸骨原发肿瘤**；任何研究类型（基础/转化/临床/流病/**【改】筛查与预防**/卫生经济学）全收，**【改】仅受"人类"与"泛癌不收"两条硬约束**。

**2. 普胸外科病**——肺/气管/支气管/**【改】食管（环咽肌以下）**/纵隔/胸壁/膈肌/**【改】胸膜腔与胸导管**的疾病及其手术与围术期研究（胸腔镜、机器人、无管化、肺段/食管切除、抗反流与裂孔疝修补、气胸/脓胸/支扩/结核的外科面、肺移植**【改】与供肺评估/体外肺灌注**、胸壁畸形矫形——含青少年患者）；**【改】新增：胸部外伤（肋骨、肺、气管、食管、胸壁、膈肌损伤）研究收；心脏及大血管原发损伤不收。围术期麻醉、ICU 管理、ERAS、术前预康复、术后并发症与术后慢性疼痛，凡研究对象为胸科手术患者，均属本圈。**

**3. 成人（≥18 岁）呼吸非肿瘤病**——COPD、哮喘、间质肺/肺纤维化、结核/NTM、肺高压、睡眠呼吸暂停、支扩/囊性纤维化、呼吸道感染（含肺炎、流感、误吸性肺炎、COVID-19 及其肺部后遗症）、ARDS、肺栓塞**【改】与下肢 DVT 的疾病研究**、戒烟/吸烟干预**【改】——限主要问题为该疾病本身或其预防、诊断、治疗；戒烟与吸烟研究若主要结局落在胸域外（如膀胱癌、心血管事件为主要终点），按总纲不收**。

**4. 胸科场景的技术**——AI、三维重建、影像组学、数字医疗、机器人与器械**【改】：研究对象与主要评价指标必须落在圈 1–3 或胸部外伤的疾病上。影像虽拍摄于胸部但终点在他科（冠脉钙化、骨质疏松、甲状腺结节、肾上腺腺瘤等）不收；多病种/多器官模型以在域疾病为主要终点或预设主要分析人群者收，泛癌或全身多病种为部署目标者不收。**

---

### 不收 · 五个圈

**1. 它科原发**（乳腺、肝胆胰胃肠、泌尿、妇产、甲状腺、颅脑、血液、皮肤、风湿免疫原发）——即便靶点/方法与胸科相通（判例：KRAS 靶点但病人是胰腺癌；PHERGain 乳腺癌降阶试验）。
**【改】例外通道（可操作判据）**：它科病，但**该胸内病灶是局部治疗（手术/放疗/介入/消融/局部灌注）的主要对象，或该病灶是主要评价终点**（如乳腺癌肺转移的 SBRT）→ 收；**以全身治疗为主要问题、胸内病灶仅为疗效评估的一部分 → 不收**。**【改】人群限定不改变病域：SLE 肺间质受累、肾移植受者肺部感染、阿尔茨海默病患者的吸入性肺炎预防等，病落在域内 → 收。**

**2. 心脏与大血管**（心梗、冠脉、心衰、心律、瓣膜、**【改】胸主动脉及其分支**）。
**【改】不属于本圈（仍收）：肺栓塞、肺高压、肺静脉病变等肺血管疾病；心脏手术后发生的胸腔并发症（乳糜胸、术后血胸、术后脓胸）按病归属，收。**

**3. 儿科/新生儿呼吸病**（小儿哮喘、毛细支气管炎、新生儿呼吸窘迫/湿肺/胎粪吸入、儿童肺炎、儿科 ARDS 等）；**【改】年龄界限：<18 岁。**
**【改】不受此限（无年龄限制，一律收）：① 胸壁/胸廓结构性畸形矫形；② 气胸、脓胸、胸腔积液与胸内肿瘤的外科或肿瘤学研究；③ 先天性结构畸形（先天性膈疝、食管闭锁、气管狭窄/气管软化、肺发育畸形）的手术与围术期研究。**

**4. 动物/兽医研究**（只收人类疾病；**【改】人源细胞系、人类样本、人体影像与临床数据均算人类研究**）。

**5. 与胸无交集的泛癌/泛外科**（**【改】训练或部署目标覆盖全癌种/全身多病种、且不以在域疾病为主要终点者；在域疾病为预设主要分析人群或主要终点的亚组研究、篮式试验 → 收**）。
