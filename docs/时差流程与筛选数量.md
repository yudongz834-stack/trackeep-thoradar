口径：2026-10-18 · 期刊字典 340 本终版 · 引擎 v3.0（已上线）

---

## 一、时差地形（三层）

**1）出版 → PubMed 入库时差（引擎拉取的锚）**
论文发表后到进 PubMed 有滞后期。引擎按 **crdt**（PubMed 记录创建日）拉取，而不是出版日——这样「新入库」的论文（含回溯入库的旧出版日论文）都会被扫到，不会因期刊提前上线而漏。

**2）PMC 型刊的加成时差**
约 84 本入库期刊是**非 MEDLINE 的 PMC 型刊**（全文走 PubMed Central 归档），入库比 MEDLINE 更慢、可能差数周。**对策：这类刊建议 30 天回溯窗**——Batch3 接字典时与时间滑杆一起定夺。

**3）调度时差（服务器时区）**
GitHub Actions 定时器只认 UTC：线上 cron `30 23 * * *`（UTC）＝**北京时间每天 07:30**。站内 `briefing_date` 用北京日期。每日体检断粮红线 36 小时，错过一天能兜住。

## 二、每日流程（六步流水线）

| 步 | 做什么 | 时差/失败怎么处理 |
|---|---|---|
| 1 采集 | PubMed ESearch：crdt 近 N 天＋标题/摘要自由词，**分页抓全**（retmax 只是页大小，总量以 Count 为准，硬顶 2000 报警）→ EFetch 拉元数据 | 窗口默认 3 天，命中不足 3 篇自动放宽到 7 天 |
| 2 定级 | **五重主键期刊索引**（ISSN-L / P-ISSN / E-ISSN / NLM ID / ISO 缩写）逐篇定档位 | 未命中字典＝B 级兜底，卡片诚实标注；S/A 级豁免白名单 |
| 3 预筛 | LLM 批量轻量筛（无 key 时启发式） | 评分来源 score_source 诚实标注「启发式」 |
| 4 精评 | LLM 结构化 PICO 精评＋反阳性偏倚条款（保护高质量阴性研究） | 无 key 则跳过，不编评语 |
| 5 核验 | 四元组核验（数值存在性＋语境锚定，fail-closed）＋出版三态（撤稿/更正/关注） | 未通过＝**解读暂停**降级展示，绝不静默放行 |
| 6 产出 | briefing md ＋ 注入 index.html 标记区间 | workflow 熔断闸：**数据无变化即判失败**（防静默断粮） |

引擎窗口参数（现状→Batch3）：
- 现状：`--days-back` 默认 2、不足放宽 7（固定档）；
- Batch3：用户**时间滑杆 1–90 天连续可调**；S/A 精选层仍以「当日锚定」出（精选找的是今天值得看的），全库雷达层交给滑杆。

## 三、筛选逻辑（四层闸门）

1. **期刊层**：340 本字典（五重主键匹配）＋档位
   - 档位规则：S=14 本固定名单（NEJM/Lancet/JAMA/Nat Med/Lancet Oncol/JAMA Oncol/Ann Oncol/JCO/Cancer Cell/Cancer Discov/JTO/Lancet Respir Med/Nature/Science）；中科院 1/2 区→A；3 区→B；4 区或未收录→C；6 本高产量刊强制 C（Cancers/Front Oncol/Sci Rep/J Thorac Imaging/Esophagus/Mediastinum）
   - 现档位分布：**S14 / A178 / B133 / C15**
2. **内容层**：标题/摘要双组自由词（v2，2026-10-18 回放对拍后定版）——
   - **病种/术式组 26 词**：NSCLC/SCLC 全称缩写、lung cancer/tumor（含英式 tumour）、肺结节/磨玻璃/亚实性、间皮瘤、thymic/胸腺瘤/纵隔肿瘤、食管癌（含 oesophageal）、食管切除（含 oesophagectomy）、胸腔镜、肺段/肺叶/全肺/亚肺叶切除、无管化、「robotic thoracic / robot-assisted thoracic」精准短语（裸词 robotic 实测 7 成妇科骨科垃圾，弃）
   - **信号组 31 词**：临床试验/随机/新辅助/辅助/围术期/倾向评分、三维/AI 四词（artificial intelligence、deep learning、machine learning、radiomics、neural network）、免疫/化疗/放疗/筛查/生存/切除、立体定向/淋巴结、EGFR/ALK/PD-L1/PD-1/ctDNA/MRD、奥希替尼/纳武/帕博/度伐利尤/抗生素
   - **回放实测（近 30 天）**：v1 词表 387 命中 → v2 1622 命中，字典内多捞 448 篇（A166/B158/C109/S15），v0⊆v2 零丢失；被漏实例含 firmonertinib 治疗 PACC 突变 NSCLC（S 档顶刊）
   - **词表纪律**：每改一次词表必跑 30 天回放对拍（D:\tmp\query_replay_audit.py 为母本），只认「字典内增量＋零丢失＋垃圾抽样」三判据
3. **影子通道（乙案并跑）**：主式之外每天并跑「全量库检索式」（病种/术式词不设信号组门槛 ∪ 歧义技术词×解剖语境），对主式增量部分用「全量库预筛口径」（普胸相关全收，含基础/转化/流病）试筛，结果落 `data/shadow/{日期}.json`；**影子失败不影响主产出**。并跑 ≥4 周，按「独有相关增量／预筛留存率／成本」决定是否切换（PI 2026-10-18 拍板方向＝全要）
4. **质量层**：预筛→精评→四元组核验＋三态，逐层降级且全部留痕
5. **精选层**：只从 S/A 出，另过一道规则闸（研究类型＋信号强度），**空态不凑数**——10-17 实测精选 0 篇就是 0 篇

## 五、用户侧控制（Batch3 语义，PI 已定）

- **时间滑杆**：1–90 天连续拖动，任意 N 天窗口
- **档位过滤**：按 S/A/B/C 勾选过滤期刊新闻
