## 一、时差地形（四层）

**1）出版 → PubMed 入库时差（引擎拉取的锚）**
论文发表后到进 PubMed 有滞后期。引擎按 **crdt**（PubMed 记录创建日）拉取，而不是出版日——这样「新入库」的论文（含回溯入库的旧出版日论文）都会被扫到，不会因期刊提前上线而漏。**ahead-of-print（在线先发）与进刊正式版是同一条 PubMed 记录**：同一 PMID，先发日入库、crdt 定格；进刊时记录原地更新（PMID/DOI 不变）——故按 PMID 去重天然不重复收，也无须用 DOI 判断新旧。

**2）PMC 型刊的加成时差**
约 84 本入库期刊是**非 MEDLINE 的 PMC 型刊**（全文走 PubMed Central 归档），入库比 MEDLINE 更慢、可能差数周。**对策：这类刊建议 30 天回溯窗**——Batch3 接字典时与时间滑杆一起定夺。

**3）调度时差（服务器时区）**
GitHub Actions 定时器只认 UTC：线上 cron `3 21 * * *`（UTC）＝**北京时间每天 05:03**（PI 2026-10-19 裁定凌晨 5 点；错开整点避 GitHub 定时高峰排队）。站内 `briefing_date` 用北京日期。每日体检断粮红线 36 小时，错过一天能兜住。

**4）标签时差（跑批机 UTC × 排队延迟，2026-10-24 实测修复）**
错开整点仍挡不住排队：GitHub 定时任务常被延迟 2-3 小时，跨 **UTC 午夜**后才起跑。引擎原用 `date.today()`（跑批机 UTC 日期）当简报标签，于是北京次日清晨的日报被标成前一天——实测 10-19 档被排到 10-20 00:08 UTC 才跑、错标 10-20，次日跑批又标 10-20，同档互相覆盖。**修复（北京日单一语义）**：引擎一切「今天」取 `bj_today()`（UTC+8 固定偏移；中国无夏令时，勿用 ZoneInfo——Windows 无系统 tzdata），简报文件名 / `briefing_date` / 日档 / 提交标题全部同源；提交标题同步改 `TZ=Asia/Shanghai date +%F`。自测第 9 块＝本修复的再现测试。历史错档（10-19 缺号、10-20 双写）为真，不回补不伪造。

## 二、双路架构（2026-10-18 定案，当日上线）

采集层＝**目录路 ∪ 检索式路**：两路各查各的，按 PMID 合并去重 → EFetch → 预筛 → 精评 → 核验 → 上站，下游与旧版一致。

**1）目录路（主路）**：340 本字典期刊逐刊用 `[ta]` 查近 3 天目录，分页抓全。字典刊天然全收——不存在词表漏法。逐刊记健康台账 `data/journal_health.json`（最后命中日期）：**45–99 天静默＝提示**（季刊可能正常）；**≥100 天零命中＝报警**（疑改名/停刊/检索键失效）。

**2）检索式路**：纯病种名 36 词直通（v3，仅 [Abstract] 摘要域；PI 第一性裁决：只病名，术式/治疗词全删）。词族＝**肺恶肿 14**（lung cancer/tumor/tumour/neoplasm、NSCLC 及全称、SCLC 及全称、LUAD/LUSC 及全称、pulmonary carcinoid）＋**肺结节 6**（pulmonary/lung nodule、ground-glass（连字符/空格两式）、subsolid、solitary pulmonary nodule）＋**胸膜 2**（mesothelioma、malignant pleural effusion）＋**食管 8**（esophageal/oesophageal × cancer/carcinoma、ESCC 及全称、esophageal adenocarcinoma）＋**纵隔胸腺 6**（thymoma、thymic carcinoma、thymic tumor/tumour、mediastinal tumor/tumour/mass）。只负责字典外世界的胸科文章——实测占命中一半以上。
- **词表纪律**：每改一次词表必跑 30 天回放对拍（`D:\tmp\query_replay_audit.py` 为母本），只认「字典内增量＋零丢失＋垃圾抽样」三判据。

**3）预筛口径（全要）**：普胸相关全收——基础/转化/临床/流病/筛查均收；旧「剔除纯细胞/动物实验」口径废止。预筛输入升级为「标题＋摘要头 300 字」。精选层规则闸不变（精选照旧从严、空态不凑数）。

## 三、每日流程（六步流水线）

| 步 | 做什么 | 时差/失败怎么处理 |
|---|---|---|
| 1 采集 | **双路并集**（见「二、双路架构」）：目录路 340 刊逐刊 `[ta]` 近 N 天＋检索式路病名 36 词直通（仅摘要域），PMID 合并去重；**分页抓全**（retmax 只是页大小，总量以 Count 为准，硬顶 2000 报警）→ EFetch 拉元数据 | 窗口默认 3 天，命中不足 3 篇自动放宽到 7 天 |
| 2 打标 | **五重主键期刊索引**（ISSN-L / P-ISSN / E-ISSN / NLM ID / ISO 缩写）逐篇打档位标签（**标签非闸门**） | 未命中字典＝B 级「未收录期刊」如实标注；**未命中且无摘要才不收录**；S/A 级豁免白名单 |
| 3 预筛 | LLM 批量轻量筛（输入＝标题＋摘要头 300 字；全量库口径：普胸相关全收） | 无 key 时启发式，score_source 诚实标注「启发式」 |
| 4 精评 | LLM 结构化 PICO 精评＋反阳性偏倚条款（保护高质量阴性研究） | 无 key 则跳过，不编评语 |
| 5 核验 | 四元组核验（数值存在性＋语境锚定，fail-closed）＋出版三态（撤稿/更正/关注） | 未通过＝**解读暂停**降级展示，绝不静默放行 |
| 6 产出 | briefing md ＋ 注入 index.html 标记区间 | workflow 熔断闸：**数据无变化即判失败**（防静默断粮） |

引擎窗口参数（现状→Batch3）：
- 现状：`--days-back` 默认 2、不足放宽 7（固定档）；
- Batch3：用户**时间滑杆 1–90 天连续可调**；S/A 精选层仍以「当日锚定」出（精选找的是今天值得看的），全库雷达层交给滑杆。
