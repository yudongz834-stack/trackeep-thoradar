## 不变量
1. `SITE_DATA` 仍是当日官方数据唯一真相；缓存只是网络响应副本。
2. 官方 `PAPERS/mergePapers/inWindow` 与个人 `localStorage` 键名、读写语义不变。
3. 当前阅读页不因后台更新或 SW 控制变化自动刷新，不丢筛选、滚动和内存状态。
4. 任何错误、截断、劫持、非 200、非 basic、错误 Content-Type 响应不得覆盖健康缓存。
5. 默认本地既有测试零 SW 注册、零缓存污染；生产只限约定 HTTPS 域。
6. 旧副本始终显示实际数据日期与核新状态；不暗示为最新。

## 核心验收场景
- 冷首访走原生网络；第二次打开本地先出屏；后台 1500ms 慢网核新不阻塞首屏。
- 新版下载后当前页保持原内容并提示下次生效；下一次导航显示新版。
- 离线、超时、404/500、认证劫持 HTML、截断 HTML、缺数据标记、错误 Content-Type 均不污染健康缓存。
- AI POST、NCBI、跨域、非导航 GET、其它同源路径不拦截。
- 低配额写失败保留健康副本；零配额或禁用 SW/Cache Storage 时原生网站可用。
- `?sw=0` 注销并清前缀缓存；自毁版清缓存、注销；再打开从网络取当前版；重装不得复活旧 HTTP 副本。
- 桌面 1440×900 与手机 390×844 均能看到数据日期和核新状态。
- 用户选择多日而档案无缓存/拉取失败时，持续明示实际只显示当日副本；本役不新增 90 天缓存。
