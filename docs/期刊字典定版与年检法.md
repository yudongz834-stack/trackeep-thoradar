## 四、年检六步（制度提案；触发＝每年初或 PI 供新表，哨兵兜底见§六）

1. **正源**：新年度分区＋IF 表走 PI 渠道；无新表→沿用＋站上明示数据截至年。
2. **存量重定档**：新表重算档位；S14 逐一复评；改名/停刊/双实体走 NLM 反查。
3. **增量补员三源**：非字典高频刊（门槛【待 PI 拍板，建议 90 天窗收录≥3 篇】）＋PI Zotero＋健康台账连续命中外来刊；候选过身份核验＋定档入册。
4. **退出**：见§五双闸。
5. **量控保留**：高产量低信号强制 C，随新表＋年发文量复核名单。
6. **收尾三件**：NLM ID＋ISSN 四维查重→独立席全量复算→说明页计数脚本动态生成。

无新表年份：第 2 步顺延，第 3/4 步仍执行（改名巡检与增量补员不依赖新表）。

## 五、退出与量控

- 除名/降 C 双闸（两条件同时满足才动名单）：①健康红灯（≥100 天无命中）②年发文量核实低于下限【待 PI 拍板，建议 vol_365<10 降 C】。
- 单条件成立不动名单，先人工核三因：改名／停刊／检索键失效。
- 预报刊不除名只降权：warned 位照标、不进精选（国际口径，现制已支持）。
- 量控名单进出都留痕；周检报告 vol_365 列即年发文量数据源。

## 六、哨兵（现有四道，字典腐化发现机制）

- **字典腐红线 400 天**：tiering.generated_at 年龄＞400 天报警，每日体检在岗（2026-10-18 定版，推算红线日 2027-11-22）。
- **周六 OpenAlex 周检**：北京周六 09:17（`.github/workflows/weekly_journal_qc.yml`→`tools/journal_qc.py`），OpenAlex 340/340 对拍＋PubMed vol_365 年量，报告落 `design/journal-qc-报告.md`。
- **健康台账**：引擎每日写 `data/journal_health.json`；45–99 天静默＝黄提示（季刊正常），≥100 天＝红报警（引擎常量 HEALTH_RED_DAYS=100）。
- **预警位 warned**：单刊预警标志位，引擎打标与消费。

## 七、判例规矩（定版踩坑实录，年检必复用）

1. 查重主键＝NLM ID＋ISSN 四维：改名刊新旧双实体曾漏网（Cancer Communications 案）；Lancet NLM ID 新旧两说以真文章 XML 实证终裁 2985213R。
2. 外来数据不可信，一律 NLM 反查：原包字典两条错 nlm_id，其中一条指向俄文脑膜炎文献。
3. 兜底分区与档位必须同源同查一处，不许两处各记一份。
4. 说明页计数必须脚本动态生成：手改漏改已复发两次。
5. Zotero 短名需别名表对官方名，不能短名直连。
6. 中间 CSV 缺列会令主键塌缩：空 ID 不参团，并集前先验列齐全。
